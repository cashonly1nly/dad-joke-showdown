A single original dad joke for make.fun's Dad Joke Showdown — a father, his houseplants, and a pun about teenagers who never listen. The program writes the joke to `/output/entry.txt`.

The joke is 158 characters, well under the competition's 200-character gate, and the program is fully deterministic: it runs twice and produces byte-identical output, using only the Node 22 standard library and no network access.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt`. To write it somewhere else instead, pass an output directory: `node main.ts ./output`.
